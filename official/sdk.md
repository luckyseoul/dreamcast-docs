# Katana SDK Index

Major public archives:
- sega-dreamcast-info.com collection (multiple versions 0.20 to R9, sources for Shinobi/Kamui)
- Archive.org dcsdk-9e and related
- Kochise/dreamcast-docs/SDK

Each release contains varying sets of hardware docs, library manuals, samples, tools.
Japanese documentation predominant in early sets; later include English.
