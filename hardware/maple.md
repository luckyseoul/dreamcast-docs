# Maple Bus

Sega proprietary serial peripheral bus.

## Features
- 4 ports, hierarchical (hubs), up to 7 devices per port
- ~2 Mbps
- Supports Controller, Analog, VMU, Keyboard, Mouse, Light Gun, Modem, LAN, etc.
