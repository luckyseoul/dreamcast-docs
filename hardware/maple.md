# Maple Bus

Sega proprietary serial peripheral bus.

## Docs
- Maple Bus 1.0 Peripheral Hardware Specifications (Controller Rev1.00 etc. on SegaRetro)
- mc.pp.se/dc/maplebus.html and maplewire.html (protocol RE)
- VMU docs

## Features
- 4 ports, hierarchical (hubs), up to 7 devices per port
- ~2 Mbps
- Supports Controller, Analog, VMU, Keyboard, Mouse, Light Gun, Modem, LAN, etc.

Device ID and data formats in official peripheral specs + community.
