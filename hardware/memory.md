# Memory Map

## Primary Regions (from Hardware Outline)
- Main SDRAM: 16 MB (64-bit, 100 MHz)
- Texture memory: 8 MB (via HOLLY)
- Sound/wave memory: 2 MB (AICA)
- Boot ROM: 2 MB
- Flash: 128 KB
- Various control registers via HOLLY and G2
