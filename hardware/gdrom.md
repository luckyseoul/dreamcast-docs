# GD-ROM

Yamaha GD-ROM drive (GigaDisk, ~1 GB Mode 1).

## Local Docs
- [Hardware Specification Outline](../files/official/Dreamcast_Hardware_Specification_Outline.pdf)
- Manuals & controller datasheets: [`files/gdrom/`](../files/gdrom/)
  - [`gdrom-manual.pdf`](../files/gdrom/gdrom-manual.pdf)
  - OTI / CXD part PDFs in the same folder
- Offline RE: [`files/mcpp/gdrom.html`](../files/mcpp/gdrom.html)

## Interface
- Via G1 bus through HOLLY
- CAV speeds 4x-12x
- Digital audio output to AICA
- Boot process loads IP.BIN from data track
