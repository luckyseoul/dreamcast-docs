# GD-ROM

Yamaha GD-ROM drive (GigaDisk, ~1 GB Mode 1).

## Docs
- Hardware Specification Outline
- mc.pp.se/dc/gdrom.html (RE)
- OTI-9220 controller notes (community)

## Interface
- Via G1 bus through HOLLY
- CAV speeds 4x-12x
- Digital audio output to AICA
- Boot process loads IP.BIN from data track

Disc format details in SDK docs and RE sources.
